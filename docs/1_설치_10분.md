# 1단계 — 작업보드 설치 (약 10분)

> 준비물: 구글 계정 하나. 끝입니다.
> 돈 드는 것 없고, 모델 API 키도 쓰지 않습니다. 만드는 건 "우리 앱 주소" 하나뿐입니다.

## 시작 전에 — 내 계정으로 되는지부터

**회사나 학교 계정(Workspace)이라면 관리자가 막아뒀을 수 있습니다.** 그런 경우엔 아무리 정확히 따라 해도 중간에 멈추는데, 이건 잘못 따라 한 게 아니라 **계정이 애초에 안 되는 것**입니다. 30분 태우기 전에 1분만 확인하세요.

구글 드라이브에서 아무 스프레드시트나 열어 **확장 프로그램 → Apps Script** 를 눌러 보세요.
편집기가 열리면 진행해도 됩니다. "관리자가 사용 중지했습니다" 같은 안내가 뜨면 그 계정으로는 안 됩니다 — 개인 지메일 계정으로 하시거나, 관리자에게 Apps Script 허용을 요청하세요.

설치 방법은 두 가지입니다. 배포자에게 **템플릿 링크**를 받았다면 A로, 이 저장소만 받았다면 B로 가세요.

---

## A. 템플릿 링크를 받은 경우 (제일 쉬움)

1. 받은 링크를 열면 "사본 만들기" 화면이 뜹니다. **사본 만들기**를 누릅니다.
   → 내 구글 드라이브에 시트가 하나 생깁니다. 앱 코드도 같이 따라옵니다.
2. 아래 **3단계(setupSheets 실행)** 부터 그대로 진행하세요.

---

## B. 이 저장소에서 직접 설치

### 1단계. 새 스프레드시트 만들기

구글 드라이브 → **새로 만들기 → Google 스프레드시트**. 이름은 `관제판` 정도로 바꿔 둡니다. (이름은 자유)

### 2단계. Apps Script 열고 파일 붙여넣기

1. 시트 상단 메뉴 **확장 프로그램 → Apps Script**. 새 탭이 열립니다.
2. 왼쪽 파일 목록의 `Code.gs` 내용을 **전부 지우고**, 이 저장소 `app/Code.gs` 를 통째로 붙여넣습니다.
3. 파일 목록 옆 **＋ → HTML** → 이름을 `Index` 로 입력(확장자 `.html` 은 자동). 내용을 전부 지우고 `app/Index.html` 을 통째로 붙여넣습니다.
4. (선택) 왼쪽 톱니 **프로젝트 설정 → "appsscript.json 매니페스트 파일 표시"** 체크 → 생긴 파일을 `app/appsscript.json` 내용으로 교체. 안 해도 배포 화면에서 같은 설정을 고를 수 있습니다.
5. 위쪽 💾 **저장**(Ctrl+S).

---

## 3단계. setupSheets 한 번 실행 → 토큰 받기

1. 편집기 위쪽 함수 드롭다운에서 **`setupSheets`** 를 고르고 **▶ 실행**.
2. 처음엔 권한 창이 뜹니다. 여기서 겁내고 되돌아가는 분이 가장 많으니 순서대로 짚겠습니다.
   - **권한 검토** → 내 구글 계정 선택
   - **"Google에서 확인하지 않은 앱입니다"** 라는 빨간 경고가 뜹니다. 남이 만든 수상한 앱이어서가 아니라, **방금 내가 내 계정에 직접 붙여넣은 코드**라서 구글이 아직 심사한 적이 없다는 뜻입니다. 이 앱은 내 시트 밖으로 아무것도 보내지 않습니다.
   - 왼쪽 아래 **고급** 을 누르면 접혀 있던 줄이 펼쳐집니다 → **"(안전하지 않음)으로 이동"** 클릭
   - 마지막으로 **허용**.
3. 아래 **실행 로그**에 `토큰: 1a2b3c…` 24자가 찍힙니다. 시트로 돌아가면 탭이 여러 개 생겨 있고, **설정** 탭에도 같은 토큰이 있습니다.
4. 예시 데이터는 아래 **6단계**에서 넣습니다. 여기서는 토큰만 확인하고 넘어가세요.

> 🔐 **이 토큰이 곧 열쇠입니다.** 앱 주소 + 토큰을 아는 사람은 이 보드를 전부 읽고 씁니다. 아무 데나 붙여넣지 마세요.
> 새 값으로 바꾸고 싶으면 설정 탭의 토큰을 고치면 그 즉시 옛 토큰은 막힙니다.

## 4단계. 웹앱으로 배포

1. 편집기 오른쪽 위 **배포 → 새 배포**.
2. 왼쪽 톱니 ⚙ → **웹 앱** 선택.
3. 설정:
   - 설명: `v1` (아무거나)
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**
4. **배포** → 권한 창이 또 뜨면 허용 → **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 둡니다.

> "모든 사용자"로 여는 게 불안해 보이지만, 이 앱은 **토큰 없이는 아무것도 보여주지 않습니다.**

## 5단계. 열어 보기

브라우저 주소창에 **`웹앱URL?token=토큰`** 을 넣습니다.

```
https://script.google.com/macros/s/…/exec?token=1a2b3c…
```

신호등·작업보드·작업일지·지시문·토론 탭이 보이면 설치 완료입니다. 이 주소를 즐겨찾기 해 두세요.

---

## 6단계. 화면이 비어 있으면 — 예시를 한 번 채워 보기

설치 직후 화면이 **텅 비어 있는 건 정상**입니다. 고장이 아닙니다.
다만 처음 보는 사람은 빈 화면만 보고는 제대로 된 건지 판단하기 어렵습니다. 예시를 한 번 넣어 눈으로 확인하고, 필요 없어지면 지우세요.

1. Apps Script 편집기로 돌아가 함수 드롭다운에서 **`seedExampleData`** 를 고르고 **▶ 실행**.
2. 앱 화면을 새로고침합니다. 잠금 3개(작업중·해제·만료 각 하나), 카드 4장, 지시문 1개, 작업일지 5줄이 들어와 있습니다.

이 한 번으로 세 가지가 눈에 들어옵니다. 잠금 상태가 색으로 갈리는 모습, 카드가 할일→하는중→끝으로 옮겨 다니는 모습, 그리고 모든 행동이 작업일지에 저절로 남는다는 것.

> ⚠️ **이미 쓰고 있는 시트에서는 눌러도 아무 일이 일어나지 않습니다.** 잠금·보드·지시문 중 하나라도 내용이 있으면 실행 로그에 `이미 데이터가 있어 예시 데이터를 넣지 않았습니다.` 만 찍히고 끝납니다. 기존 데이터에 예시가 섞이거나 덮어써지는 일은 없습니다.

예시를 치우려면 시트의 **잠금·보드·지시문·일지** 탭에서 첫 줄(머리글)만 남기고 지우면 됩니다. 토론 탭에는 예시가 들어가지 않습니다.

---

## 7단계. 같이 쓸 사람·프로젝트 등록

시트 **설정** 탭에서 두 칸만 고치면 됩니다. 코드 배포를 다시 할 필요 없이 저장하면 바로 적용됩니다.

- `행위자목록` — 쉼표로 구분. 예: `나,클로드,ChatGPT,헤르메스`
- `프로젝트목록` — 예: `관제판,우리앱`

⚠️ 목록에 없는 이름으로 호출하면 앱이 `unknown_actor` / `unknown_project` 로 **거부**합니다. 오타로 엉뚱한 잠금이 생기는 걸 막기 위한 장치입니다. 공백·오타 없이 쉼표로만 구분하세요.

---

## 8단계 (선택). 명령줄에서 쓰기

AI 에이전트나 스크립트가 관제판을 부르려면 파이썬 클라이언트를 씁니다.

1. `client/gwanje.config.example.json` 을 같은 폴더에 **`gwanje.config.json`** 으로 복사합니다.
2. `url`(4단계에서 복사한 웹앱 주소), `token`(3단계 토큰), `actor`(설정 탭 행위자목록에 있는 내 이름), `project` 를 채웁니다.
3. 확인:

```
cd client
python gwanje_client.py doctor
```

`✅ 가동 준비 완료` 가 나오면 됩니다. ✗ 가 있으면 그 줄의 `→` 안내대로 고치고 다시 돌리세요.

자주 쓰는 명령:

```
python gwanje_client.py status                     # 지금 상태
python gwanje_client.py poll                       # 나한테 필요한 것만
python gwanje_client.py claim <파일경로> --memo "무엇을 할지"
python gwanje_client.py release <파일경로>
python gwanje_client.py log "무엇을 했는지"
```

## 막힐 때

| 증상 | 원인·해결 |
|---|---|
| 화면에 `unauthorized` 만 나옴 | 주소 끝에 `?token=…` 을 안 붙였거나 토큰이 틀림 |
| `unknown_actor` / `unknown_project` | 설정 탭 목록에 그 이름이 없음. 오타·공백 확인 |
| `locked` 로 거부됨 | 그 파일은 남이 잡고 있음. 정상 동작입니다 |
| 실행 로그에 토큰이 안 찍힘 | `setupSheets` 를 고르지 않고 다른 함수를 실행했을 수 있음 |
| Apps Script 가 아예 안 열림 / 실행이 거부됨 | 회사·학교 계정이면 관리자가 막아둔 것. 내 잘못이 아니니 개인 계정으로 하거나 관리자에게 요청 |
| 코드를 고쳤는데 화면이 그대로 | 배포 → **배포 관리 → 편집(연필) → 버전: 새 버전** 으로 다시 배포해야 반영됨 |

이 앱은 신호등이지 Git 이 아닙니다. 되돌리기가 없으니 `claim` 을 먼저 하는 습관이 전부입니다.
