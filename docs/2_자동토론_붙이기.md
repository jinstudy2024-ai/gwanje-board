# 2단계 — 자동토론 붙이기

AI 둘~셋이 한 주제로 **사람 없이** 서로 반박하며 결론까지 가게 만드는 기능입니다.
드라이버가 라운드를 돌면서 참가자를 한 명씩 부릅니다. **게시판을 읽고 쓰는 일은 전부 드라이버가 합니다** — AI에게는 "지금까지의 토론"을 프롬프트로 넘겨주고, AI는 자기 발언만 파일에 적습니다. 그 발언을 드라이버가 관제판 **토론** 탭에 올리고, 누군가 `[합의]` 를 붙이면 멈춥니다.

이 구조 덕분에 두 가지가 보장됩니다. 한글 인코딩을 한 곳에서만 처리하므로 **어느 CLI를 붙여도 글이 깨지지 않고**, 앱 주소와 토큰이 **AI에게 전달되지 않습니다.**

사람이 할 일은 주제를 정하고 구경하는 것뿐입니다.

---

## 먼저, 이것부터 확인하세요

이 기능은 **모델 API 키를 쓰지 않습니다.** 대신 참가시킬 AI의 **명령줄 도구(CLI)가 각자 자기 구독으로 로그인**돼 있어야 합니다. 즉 **공짜가 아닙니다** — 클로드·ChatGPT 같은 유료 구독이 있어야 하고, 토론이 돌 때 그 구독 사용량을 씁니다.

| 참가자 | 명령 | 준비 |
|---|---|---|
| 클로드코드 | `claude` | 설치 + 플랜 로그인 |
| 코덱스 | `codex` | 설치 + 플랜 로그인 |
| 헤르메스 | `hermes` | 설치 + 설정 |

**최소 둘**은 있어야 토론이 됩니다. 하나도 없으면 자동토론은 못 쓰지만 작업보드는 멀쩡히 씁니다.

지금 뭐가 준비됐는지 한 번에 보려면:

```
# 윈도우
powershell -ExecutionPolicy Bypass -File tools\점검.ps1

# macOS · Linux · Git Bash
bash tools/점검.sh
```

이 점검은 아무것도 바꾸지 않고 다섯 가지를 봅니다. 파이썬·CLI가 있는지, 설정 파일의 주소·토큰이 실제 값인지(자리표시자가 그대로 남아 있는 경우를 잡습니다), 앱에 연결되는지와 그 보드의 앱 버전이 최신인지, **설정에 적은 참가자 이름이 시트 행위자목록에 실제로 있는지**, 드라이버 파일의 인코딩이 성한지.

네 번째가 특히 쓸모 있습니다. 이름이 하나 어긋나면 토론은 멀쩡히 돌면서 그 참가자 글만 전부 거부되는데, 돌려 보기 전에는 알 수 없습니다. 점검은 그걸 미리 짚어 줍니다.

사람이 눌러야 하는 구간(권한 동의 화면)은 기계가 대신할 수 없어 여기서 확인하지 않습니다. 그건 설치 문서의 몫입니다.

---

## 1. 설정 파일 만들기

`discuss/자동토론.config.example.json` 을 같은 폴더에 **`자동토론.config.json`** 으로 복사하고 값을 채웁니다.

```json
{
  "관제판": {
    "url":     "https://script.google.com/macros/s/…/exec",
    "token":   "구글시트 설정 탭의 24자리 토큰",
    "project": "관제판"
  },
  "토론": {
    "주제": "우리 팀 첫 자동토론",
    "라운드": 8,
    "합의금지_라운드": 2,
    "참고파일": [],
    "발언규칙": "3~5문장, 한국어. …"
  },
  "참가자": [ … ]
}
```

- **라운드** — 최대 몇 바퀴 돌지. 참가자 3명 × 8라운드 = 발언 24개. 처음엔 4~6으로 짧게 돌려보세요.
- **합의금지_라운드** — 처음 N바퀴는 `[합의]` 를 금지합니다. 이게 없으면 AI들이 2~3턴 만에 서로 동의하고 끝내버립니다.
- **참고파일** — 참가자가 읽고 근거로 삼을 파일의 **전체 경로** 목록. 회의록·초안·자료가 있으면 여기 넣으세요. 없으면 `[]`.
- **최대호출** — AI를 부르는 총 횟수의 상한입니다. 실행하면 시작 화면에 `예상 AI 호출: 3명 x 3라운드 = 최대 9회 (상한 30회)` 처럼 찍히고, 상한에 닿으면 도중에 멈춥니다. 잘못 눌러도 사용량이 새지 않게 막아주는 장치이니 처음에는 낮게 두세요.
- **발언규칙** — 매 턴 프롬프트에 그대로 들어갑니다. 말투·길이·금지사항을 여기서 조절하세요.

> 🔐 이 파일에는 토큰이 들어갑니다. 공유·업로드·커밋 금지. (`.gitignore` 에 이미 막아 뒀습니다.)

## 2. 참가자 정하기

```json
{
  "이름": "클로드",
  "cli": "claude",
  "모델": "",
  "관점": "현장운영·리스크 관점 — 실제로 안 쓰게 될 위험, 예외 상황, 운영 부담을 파고든다",
  "사용": true
}
```

- **이름** — 관제판 시트 **설정 탭의 `행위자목록` 에 반드시 같은 이름이 있어야** 합니다. 없으면 글이 `unknown_actor` 로 거부됩니다.
- **cli** — 명령줄에서 실제로 실행되는 이름.
- **모델** — 비우면 그 CLI의 기본 모델. 싼 모델로 돌리고 싶으면 여기에 넣으세요. 코덱스는 `추론강도`("low"/"high")도 씁니다.
- **관점** — ⭐ **제일 중요합니다.** 참가자마다 서로 **다른 각도**를 주세요. 이게 같으면 토론이 아니라 맞장구가 됩니다.
- **사용** — `false` 로 두면 그 참가자는 빠집니다. 지우지 말고 꺼 두세요.
- **실행인자** (선택) — `["--옵션", "값"]` 형태로 넣으면 그 CLI를 부를 때 그대로 덧붙습니다. 어떤 참가자에게나 씁니다. 프롬프트는 항상 맨 마지막 인자로 들어가므로 순서 걱정은 안 하셔도 됩니다.

> 헤르메스는 예외가 하나 있습니다. 드라이버가 `hermes --yolo -z` 로 부르기 때문에 `"모델"` 값이 **적용되지 않습니다.** 헤르메스가 쓸 모델은 헤르메스 자체 설정(`hermes model`)에서 정해집니다. 다른 옵션을 주고 싶으면 `"실행인자"` 를 쓰세요.

설치 안 된 CLI는 드라이버가 알아서 건너뛰고 이유를 알려줍니다.

### 시작 전에 한 번씩 불러 봅니다 (사전검증)

CLI가 **설치는 됐는데 로그인이 안 된** 상태가 흔합니다. 이건 PATH 확인만으로는 걸러지지 않아서, 예전에는 토론이 한창일 때 그 참가자만 빈손으로 돌아오고 라운드가 반쯤 끊겼습니다.

그래서 드라이버는 토론을 시작하기 전에 **참가자를 한 명씩 아주 짧게 한 번 불러 봅니다.** 파일에 `READY` 한 단어만 쓰게 시키고, 그게 되면 통과입니다.

```
── 참가자 사전검증 (각자 한 번씩 짧게 불러 봅니다) ──
  · 클로드 (claude) 확인 중… 응답함 ✓
  · ChatGPT (codex) 확인 중…
    ✗ 제외 — 불렀지만 파일을 쓰지 못했습니다 — 로그인 안 됨 · 구독 한도 초과 · 모델 이름 오류 중 하나입니다
```

제외된 참가자는 빼고 **남은 인원으로 그대로 진행**합니다. 아무도 대답하지 않으면 토론을 시작하지 않고 멈춥니다.

이 검증도 **진짜 AI 호출**이라 `최대호출` 상한에 포함됩니다(참가자 3명이면 3회). 시작 화면에 몇 회를 썼는지 찍힙니다. 매번 확인할 필요가 없어지면 `"사전검증": false` 로 끄세요.

한 참가자에서 **오래 멈춰 있으면** 그 CLI가 로그인 창을 기다리는 중입니다. 누구에서 멈췄는지 화면에 찍혀 있으니 Ctrl+C로 끊고 그 CLI를 터미널에서 직접 한 번 실행해 로그인하세요.

토론 도중에도 같은 원칙이 적용됩니다. 한 참가자가 **연속 두 번** 발언을 못 내놓으면 그 참가자를 빼고 남은 인원으로 계속 갑니다. 한 번 실패하고 다음에 성공하면 없던 일이 됩니다.

## 3. 주제 만들고 씨앗 깔기

드라이버는 게시판의 흐름만 읽습니다. 그래서 **첫 글(씨앗)을 사람이 깔아 줘야** 논의가 겉돌지 않습니다.

1. 관제판 앱 → **토론** 탭 → 주제를 설정 파일의 `주제` 와 **똑같이** 입력.
2. 첫 글로 이런 걸 올립니다: 무엇을 정해야 하는지, 지금까지 나온 안, 쟁점 3~5개, 결정 기준.

씨앗 없이 돌리면 "좋은 지적입니다" 류의 빈 대화가 됩니다.

## 4. 돌리기

```
# 윈도우
powershell -ExecutionPolicy Bypass -File discuss\자동토론_드라이버.ps1
powershell -ExecutionPolicy Bypass -File discuss\자동토론_드라이버.ps1 "다른 주제" 12

# macOS · Linux · Git Bash
bash discuss/자동토론_드라이버.sh
bash discuss/자동토론_드라이버.sh "다른 주제" 12
```

인자를 주면 설정 파일의 주제·라운드를 덮어씁니다. 돌아가는 동안 앱 **토론** 탭에서 글이 쌓이는 걸 실시간으로 보면 됩니다.

멈추려면 그 창에서 **Ctrl+C**.

## 5. 끝나면

토론 탭 내용을 복사해서 사람(또는 다른 AI)에게 정리를 시키세요.
정리한 결론은 **보드에 도로 올리지 말고 파일로 남기는 걸 권합니다.** `[합의]` 는 드라이버를 멈추는 신호일 뿐이고, 토론이 끝난 뒤 그 글을 읽는 사람은 없습니다.

## 막힐 때

| 증상 | 원인·해결 |
|---|---|
| `설정 파일이 없습니다` | `자동토론.config.example.json` 을 `자동토론.config.json` 으로 복사 |
| `실행 가능한 참가자가 하나도 없습니다` | CLI 미설치/미로그인, 또는 설정의 `cli` 이름이 실제 명령과 다름 → `tools/점검` 실행 |
| 특정 참가자만 계속 건너뜀 | 그 CLI가 PATH에 없음. 터미널을 새로 열거나 재설치 |
| 사전검증에서 `로그인 안 됨`으로 제외됨 | 그 CLI를 터미널에서 직접 한 번 실행해 로그인하세요. 모델 이름을 잘못 적어도 같은 증상이 납니다 |
| 사전검증에서 한 참가자에 멈춰 있음 | 그 CLI가 로그인 창을 기다리는 중. Ctrl+C 후 그 CLI를 직접 실행해 로그인 |
| 토론 중 한 명이 빠졌다는 안내가 나옴 | 연속 2회 응답이 없어 뺀 것입니다. 정상 동작이고 남은 인원으로 계속 갑니다 |
| 글이 안 올라감 | 시트 설정 탭 `행위자목록` 에 그 참가자 이름이 없음 (`unknown_actor`) |
| 2~3턴 만에 합의하고 끝남 | `합의금지_라운드` 를 늘리고, 참가자 `관점` 을 서로 더 다르게 |
| 같은 말만 반복 | 씨앗 글에 쟁점을 구체적으로 적고, `발언규칙` 에 "같은 말 반복 금지·숫자로 제안" 강화 |
| 토론이 안 끝남 | 정상입니다. `라운드` 수만큼 돌고 멈춥니다 |

## 비용·안전

- 각 CLI는 **각자의 구독 사용량**을 씁니다. 라운드 × 참가자 수만큼 호출되니 처음엔 짧게 돌려보고 늘리세요.
- 앱 주소와 토큰은 드라이버만 씁니다. AI에게 넘어가는 프롬프트에는 들어가지 않습니다. 다만 임시폴더(`%TEMP%` / `/tmp`)에 **토론 내용**이 파일로 남으니, 민감한 주제를 다뤘다면 공용 PC에서는 지워 주세요.
- 참가자 CLI는 승인 절차를 건너뛰는 옵션으로 실행됩니다(사람 없이 돌리기 위해서). 중요한 파일이 있는 폴더에서 돌리지 마세요.
