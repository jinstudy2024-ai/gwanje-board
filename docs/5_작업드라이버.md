# 5단계 — 작업 드라이버 붙이기

자동토론(2단계)이 "무엇을 할지"를 정하는 도구라면, **작업 드라이버는 정해진 카드를 AI가 실제로 처리하는 도구**입니다.

관제판 신호등의 **잡았다 → 작업 → 풀기** 릴레이를, 이번엔 **코드 수정**에 그대로 적용합니다.
사람은 작업보드에 개선 카드(할일)만 올리고, 명령 한 줄을 돌리면:

> 드라이버가 `할일` 카드를 읽어 → 카드의 담당에 맞는 AI(CLI)를 불러 대상 파일을 고치게 하고 → 잠금을 걸었다 풀며 → 카드를 `끝`으로 옮깁니다.

여러 담당이 섞여 있으면 카드마다 그 담당의 CLI를 불러 처리합니다 — **서로 다른 AI가 자동으로 이어받는 릴레이**입니다.

---

## 먼저, 이것부터 확인하세요

- **작업보드 설치가 끝나 있어야** 합니다(1단계).
- 처리할 카드의 **담당 이름마다 그 CLI가 설치·로그인**돼 있어야 합니다. `claude`·`codex`·`hermes` 중 필요한 것.
- 설정은 **자동토론과 별개**입니다. 작업 드라이버는 `client/gwanje.config.json`(작업보드 클라이언트 설정)을 그대로 쓰고, 거기에 **작업** 블록만 더 읽습니다.

지금 뭐가 준비됐는지 한 번에:

```
# 윈도우
powershell -ExecutionPolicy Bypass -File tools\점검.ps1
# macOS · Linux · Git Bash
bash tools/점검.sh
```

`작업 드라이버 — 담당 CLI N개 준비됨` 이 보이면 됩니다.

---

## 1. 설정 채우기

`client/gwanje.config.json` 이 없으면 `client/gwanje.config.example.json` 을 복사해 만들고,
`url`·`token`·`project`·`actor` 를 채운 뒤 **작업** 블록을 확인하세요.

```json
"작업": {
  "최대카드": 5,
  "모드": "once",
  "사전검증": true,
  "작업폴더": "",
  "카드제한초": 0,
  "병렬": false,
  "최대동시": 3,
  "작업규칙": "기존 코드 스타일·한글 주석을 유지하고, 테스트가 있으면 깨지 마라.",
  "담당": [
    { "이름": "클로드", "cli": "claude", "모델": "", "실행인자": [] },
    { "이름": "ChatGPT", "cli": "codex", "모델": "", "추론강도": "", "실행인자": [] },
    { "이름": "헤르메스", "cli": "hermes", "실행인자": [], "사용": false }
  ]
}
```

- **최대카드** — 한 바퀴에 처리할 카드 수 상한(비용 안전장치). 처음엔 1~2로 짧게.
- **모드** — `once`(밀린 할일 1회 처리) / `watch`(폴링).
- **사전검증** — 작업 전에 각 담당 CLI를 한 번 불러 실제로 대답하는지 확인(로그인 안 된 CLI 거르기).
- **작업폴더** — CLI가 파일을 고칠 폴더. 비우면 **이 저장소 루트**. ⚠ 아래 안전 참고.
- **카드제한초** — 카드 한 장당 제한시간(초). 0 이면 무제한.
- **병렬** — `true` 면 여러 카드를 담당별로 **동시에** 처리합니다(같은 파일 카드는 자동으로 순서대로). 기본은 `false`(한 장씩).
- **최대동시** — 병렬일 때 한 번에 몇 개까지 동시에 돌릴지(기본 3). 동시 실행 수만큼 **비용도 함께** 늘어납니다.
- **담당** — 카드의 `담당` 이름 → 그 이름의 `cli` 로 처리. **시트 행위자목록에도 같은 이름이 있어야** 합니다.

> 🔐 이 파일에는 토큰이 들어갑니다. 공유·업로드·커밋 금지(`.gitignore` 에 이미 막아 뒀습니다).

## 2. 카드 올리기

작업보드에 **할일** 카드를 만듭니다. 카드마다:

- **담당** — 위 설정의 담당 이름 중 하나(누가 처리할지).
- **관련자원** — 고칠 대상 파일 경로(예: `app/Code.gs`). 드라이버가 이걸 잠급니다.
- **메모** — 무엇을 어떻게 고칠지 지시. 이게 곧 AI에게 가는 지시문입니다.
- **우선순위** — 높음→보통→낮음 순으로 처리합니다.

메모가 구체적일수록 결과가 좋습니다. "반올림 버그" 보다 "가닥수 산정에서 소수점 올림을 내림으로 바꿔라"가 낫습니다.

## 3. 돌리기

```
# 윈도우
powershell -ExecutionPolicy Bypass -File 작업\작업드라이버.ps1
powershell -ExecutionPolicy Bypass -File 작업\작업드라이버.ps1 내프로젝트 once

# macOS · Linux · Git Bash
bash 작업/작업드라이버.sh
bash 작업/작업드라이버.sh 내프로젝트 watch
```

첫 인자는 프로젝트, 둘째는 모드(`once`/`watch`)입니다. 안 주면 설정값을 씁니다.
시작하면 담당 사전검증 → `예상: N개 카드 처리` 안내 → **Enter로 확인** 후 처리합니다.
돌아가는 동안 앱 **작업보드**·**작업일지** 탭에서 카드가 옮겨 다니는 걸 실시간으로 보면 됩니다.

## 4. 카드 하나가 처리되는 순서

1. `claim` — 카드의 관련자원을 잠근다. **남이 잡고 있으면 건너뛴다**(교통정리). 
2. `card_move 하는중` — 지금 처리 중임을 보드에 표시.
3. 담당 CLI를 **작업폴더에서** 실행 — "대상 파일만 고쳐라. 지시=메모. 다 되면 한 줄 요약." (긴 작업이면 30분마다 `heartbeat` 로 잠금 연장.)
4. **성공** → `release` → `card_move 끝` → `log 완료`.
5. **실패/시간초과** → `release` → `card_move 할일`(되돌림) → 사유를 `log`. 다음 카드로.

## 여러 AI를 동시에 (병렬)

`병렬: true` 로 두면 드라이버 **하나**로 담당들이 **동시에** 서로 다른 카드를 물고 일합니다. 창을 여러 개 띄울 필요가 없어요.

- 서로 **다른 파일**을 고치는 카드는 나란히 진행됩니다.
- 어쩌다 **같은 파일**을 가리키는 카드가 둘이면, 드라이버가 자동으로 **순서대로** 돌려 충돌(덮어쓰기)을 막습니다.
- `최대동시` 로 한 번에 몇 개까지 돌릴지 정합니다. **동시에 돌리는 수만큼 비용이 한꺼번에** 나가니, 처음엔 2~3으로 시작하세요.

---

## 비용·안전 (반드시 읽으세요)

- 담당 CLI는 **파일쓰기 권한**(claude `--dangerously-skip-permissions` 등, 사람 승인 건너뜀)으로 돕니다. 즉 작업폴더의 파일을 **AI가 마음대로 고칠 수 있습니다.**
- 그래서 실행 범위를 **작업폴더 하나로 한정**하고, 시작 화면에서 **한 번 확인**을 받습니다. 그래도:
  - **지울 수 없는 중요한 원본이 든 폴더에서는 돌리지 마세요.** 개발용 사본을 따로 두고 그 폴더를 `작업폴더` 로 지정하세요.
  - **버전 관리(git) 아래에서 돌리길 권합니다.** 잘못되면 되돌릴 수 있게.
  - `최대카드` 를 작게 두고, 처음엔 카드 1장으로 결과를 확인한 뒤 늘리세요.
- 각 CLI는 **각자의 유료 구독 사용량**을 씁니다. 모델 API 키는 쓰지 않습니다.

## 막힐 때

| 증상 | 원인·해결 |
|---|---|
| `작업 가능한 담당 CLI가 하나도 없습니다` | 설정 `작업.담당` 의 `cli` 이름이 실제 명령과 다르거나 미설치. `tools/점검` 실행 |
| 특정 담당 카드만 건너뜀 | 그 담당 이름의 CLI가 없음(설정 확인), 또는 시트 행위자목록에 그 이름이 없음 |
| `locked` 로 건너뜀 | 그 자원을 남이 잡고 있음. 정상 동작(겹침 방지)입니다 |
| 카드가 자꾸 `할일` 로 되돌아옴 | CLI가 오류로 끝났거나 시간초과. 일지의 실패 사유를 보고 메모를 더 구체적으로 |
| 사전검증에서 제외됨 | 그 CLI가 로그인 안 됨. 터미널에서 직접 한 번 실행해 로그인 |
