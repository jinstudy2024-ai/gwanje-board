# 배포자용 — 템플릿 시트 만들어 나눠주기

> 이 문서는 **남에게 나눠주는 사람**이 한 번만 읽으면 되는 문서입니다. 받는 사람은 볼 필요 없습니다.

받는 사람에게 "Apps Script 열어서 58KB짜리 HTML을 붙여넣으세요"라고 하면 절반은 중간에 포기합니다.
대신 **앱이 심어진 빈 시트를 템플릿으로 만들어 "사본 만들기" 링크**를 주면, 받는 사람은 클릭 한 번으로 코드까지 통째로 복사합니다. 구글 시트에 붙은 Apps Script는 사본에 따라오기 때문입니다.

---

## ⚠️ 가장 중요한 함정 — 템플릿에서 `setupSheets` 를 실행하지 마세요

`setupSheets` 를 실행하면 그 시트에 **토큰이 생성돼 설정 탭에 저장**됩니다.
그 상태로 템플릿을 공유하면 **사본을 받은 모든 사람이 같은 토큰을 갖게 됩니다.** 그리고 `setupSheets` 는 이미 데이터가 있으면 건너뛰므로, 받는 사람이 다시 실행해도 새 토큰이 생기지 않습니다.

→ 템플릿은 **코드만 심고 한 번도 실행하지 않은 상태**로 공유하세요.
→ 받는 사람이 자기 사본에서 `setupSheets` 를 처음 실행할 때 **자기만의 토큰**이 생깁니다.

이미 쓰던 시트를 복사해서 템플릿을 만들었다면, 공유 전에 **설정 탭의 토큰 값을 지우고, 잠금·보드·일지·토론 탭의 내용도 비우세요.**

---

## 만드는 순서

1. 구글 드라이브에서 **새 스프레드시트**를 하나 만듭니다. 이름: `관제판 (템플릿)`
2. **확장 프로그램 → Apps Script** → `Code.gs` 내용을 이 저장소 `app/Code.gs` 로 교체.
3. **＋ → HTML** → 이름 `Index` → `app/Index.html` 내용 붙여넣기.
4. (선택) 프로젝트 설정에서 매니페스트 표시 → `app/appsscript.json` 으로 교체.
5. **저장만 하고, 아무 함수도 실행하지 않습니다.** (위 경고 참고)
6. 시트로 돌아와 **공유 → 일반 액세스 → 링크가 있는 모든 사용자 → 뷰어**.
7. 링크를 복사한 뒤, 주소 끝의 **`/edit…` 부분을 `/copy` 로 바꿉니다.**

```
https://docs.google.com/spreadsheets/d/<ID>/edit?usp=sharing
                                          ↓
https://docs.google.com/spreadsheets/d/<ID>/copy
```

이 `/copy` 링크를 받은 사람은 "사본 만들기" 버튼만 누르면 됩니다.

## 시트 맨 앞에 "읽어보기" 시트 두기

템플릿만 받은 사람은 저장소를 안 볼 수도 있습니다. 사본을 열자마자 눈에 띄는 자리에 다음 할 일을 적어 두세요.

새 스프레드시트에 원래 있는 `시트1` 의 이름을 **`읽어보기`** 로 바꾸고, 탭을 **맨 왼쪽**으로 끌어다 둔 뒤 아래를 붙여넣으면 됩니다. (`setupSheets` 는 이름이 다른 시트를 건드리지 않으니 그대로 둬도 안전합니다.)

```
이 시트는 "관제판" — 여러 AI와 사람이 같은 프로젝트를 건드릴 때 쓰는 신호등입니다.

1. 상단 메뉴 [확장 프로그램] → [Apps Script] 를 엽니다.
2. 위쪽 함수 목록에서 setupSheets 를 골라 ▶ 실행합니다. (권한 창이 뜨면 허용)
   → 실행 로그에 찍히는 24자리 토큰을 복사해 둡니다. 이 토큰이 열쇠입니다. 남에게 주지 마세요.
3. 오른쪽 위 [배포] → [새 배포] → 웹 앱 →
   "실행: 나", "액세스: 모든 사용자" 로 배포하고 주소를 복사합니다.
4. 브라우저에 "복사한주소?token=복사한토큰" 을 입력하면 화면이 열립니다.

자세한 설명과 자동토론 기능: <여기에 저장소 주소를 적으세요>
```

## 같이 줄 것

- 위 `/copy` 링크
- 이 저장소 주소 (문서·클라이언트·자동토론 드라이버가 들어 있음)
- 한 줄 안내: **"사본 만들고 → docs/1_설치_10분.md 의 3단계부터 따라 하세요"**

## 배포 전 점검

- [ ] 템플릿 시트에 토큰·이전 데이터가 남아 있지 않은가
- [ ] 저장소에 `gwanje.config.json` / `자동토론.config.json` (실제 값)이 섞여 있지 않은가 — `*.example.json` 만 있어야 함
- [ ] 문서·스크립트에 내 웹앱 주소나 토큰이 남아 있지 않은가
- [ ] 고객사 자료·회의록 경로 같은 비공개 내용이 예시로 들어가 있지 않은가
- [ ] `LICENSE` 의 저작권자 이름을 채웠는가
- [ ] 템플릿 시트의 `읽어보기` 시트에 저장소 주소를 적었는가
- [ ] `node test/run_tests.js` 가 132개 전부 통과하는가

간단히 훑어보려면:

```
# 저장소 폴더에서 (윈도우 PowerShell)
Select-String -Path .\* -Pattern "script.google.com/macros" -Recurse

# macOS · Linux · Git Bash
grep -rn "script.google.com/macros" .
```

`*.example.json` 과 문서의 설명용 `…/exec` 자리표시자 말고 **실제 주소가 나오면 안 됩니다.**

## 업데이트를 나눠줄 때

앱 코드(`Code.gs`·`Index.html`)를 고쳤다면 받은 사람들은 각자 **Apps Script에 새 코드를 붙여넣고 배포 → 배포 관리 → 새 버전**을 해야 반영됩니다. 시트 데이터는 그대로 유지됩니다.
저장소에 변경 이력을 남겨 두면 "무엇이 바뀌었는지"를 각자 확인할 수 있습니다.
