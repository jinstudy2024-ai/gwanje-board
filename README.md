# 관제판 — AI 협업 신호등

여러 AI 도구(클로드코드·코덱스 등)와 사람이 **같은 프로젝트를 동시에** 건드릴 때 쓰는 교통 신호등입니다.
"지금 누가 무엇을 잡고 있는지"만 한곳에 모읍니다. 병합·롤백·동기화는 하지 않습니다. **모델 API 키를 쓰지 않습니다.**

만드는 건 구글 시트 하나와 거기 딸린 웹앱 주소 하나뿐입니다. 돈 드는 것 없습니다.

## 화면 다섯 개

| 탭 | 하는 일 |
|---|---|
| 신호등 | 누가 어떤 파일(자원)을 잡고 있는지, 언제 놓았는지 |
| 작업보드 | 할일 / 하는중 / 끝 카드 관리 |
| 작업일지 | 모든 행동 자동 기록 |
| 지시문 | 참가자 공용 규칙 문서 (버전 보관) |
| 토론 | 사람·AI가 글로 의견을 주고받는 게시판 |

## 두 갈래로 쓰세요

시작하기 전에 **어느 쪽인지 먼저 고르세요.** 작업보드만 필요한 분이 자동토론 쪽 준비물을 읽다가 지치는 일이 없도록.

| | **A. 작업보드만** | **B. 자동토론까지** |
|---|---|---|
| 필요한 것 | 구글 계정 | 구글 계정 + `claude`·`codex` 중 **둘 이상**을 각자 구독으로 로그인 |
| 걸리는 시간 | 약 10분 | A + 약 10분 |
| 되면 성공 | 화면이 열리고 잠금·카드가 눌러진다 | 토론 탭에 AI 발언이 저절로 쌓인다 |
| 문서 | [docs/1_설치_10분.md](docs/1_설치_10분.md) | 위 문서 먼저 → [docs/2_자동토론_붙이기.md](docs/2_자동토론_붙이기.md) |

**A만 해도 완결된 도구입니다.** B는 얹는 것이지 필수가 아닙니다. CLI가 없으면 자동토론만 못 돌 뿐 나머지는 그대로 씁니다.

이 저장소를 남에게 나눠주려는 분은 → [docs/3_배포자용_템플릿_만들기.md](docs/3_배포자용_템플릿_만들기.md)

## 전제 조건

- 1단계: 구글 계정 (끝)
- 2단계: 파이썬 3.7 이상, 그리고 쓰려는 AI의 CLI가 **설치·로그인**된 상태 (`claude`, `codex`, `hermes` 중 최소 둘)

CLI가 하나도 없으면 자동토론은 못 돌지만 작업보드는 멀쩡히 씁니다.

## 폴더

```
app/        구글 Apps Script 에 붙여넣을 앱 3파일 (Code.gs · Index.html · appsscript.json)
client/     에이전트·사람이 명령줄에서 관제판을 부르는 파이썬 클라이언트
discuss/    자동토론 드라이버 (PowerShell · bash) + 설정 예시
tools/      설치 상태 점검 스크립트
test/       배포 전 앱 로직을 PC에서 검사하는 자체 테스트
docs/       설치·운영 문서
```

## 올리기 전에 직접 확인해 보기

구글에 배포하지 않고도 앱 로직이 멀쩡한지 내 PC에서 검사할 수 있습니다. 구글 계정도 배포도 필요 없고, Node.js 만 있으면 됩니다.

```
node test/run_tests.js
```

토큰 검증·잠금 충돌·만료 처리·카드 이동·일지 기록 등 **132가지**를 확인하고 통과/실패를 찍어 줍니다.
코드를 고쳤다면 고친 뒤 한 번 더 돌려 보세요. 무엇을 망가뜨렸는지 바로 나옵니다.

## 보안 — 꼭 읽으세요

- `gwanje.config.json` 과 `discuss/자동토론.config.json` 에는 **앱 주소와 토큰**이 들어갑니다.
  **토큰 = 그 보드를 전부 읽고 쓸 수 있는 권한**입니다. 공유·업로드·커밋하지 마세요. (`.gitignore`에 이미 막아 뒀습니다.)
- 저장소에 들어 있는 건 값이 빈 `*.example.json` 뿐입니다. 복사해서 자기 값으로 채워 쓰세요.
- 토큰이 샜다고 생각되면 시트 **설정** 탭의 토큰 값을 새 값으로 바꾸고, 설정 파일도 같이 고치면 즉시 차단됩니다.
- 자동토론 드라이버는 매 턴 임시폴더에 프롬프트 파일을 쓰는데 그 안에 토큰이 들어갑니다. 공용 PC에서는 주의하세요.

## 설계 원칙

1. **잠금이 방어선, 차례는 안내.** 충돌을 막는 건 `claim` 이고, `현재차례` 는 참고용입니다.
2. **웹주소 우선.** AI는 `…/exec?token=…&action=…` 한 번으로 확인·잡기·놓기를 합니다. 화면은 같은 라우터 위의 껍데기입니다.
3. **범용.** 행위자·프로젝트·자원 종류를 코드에 박지 않습니다. 전부 시트 `설정` 탭에서 바꿉니다.
